## Source order

1. **Research claims:** open the DOI and inspect the original paper, supplementary material and stated limitations.
2. **Track-level research:** inspect the relevant GitHub repository's source files and versions.
3. **Essay or analysis claims:** follow the original note article URL.
4. **Concept relationships and reading paths:** consult the [concept map](CONCEPT_MAP.html), [detailed archive](RESEARCH_ARCHIVE_DETAILS.html), and [AI reader guide](FOR_AI_READERS.html).

Neither this page nor the JSON manifest establishes scientific validity, independent replication or the latest non-public project state.

## Public scope

This guide is for re-entering **publicly available material**. It is not a private conversation archive, an internal project restart file or a disclosure of non-public implementation methods. Continuing confidential work requires its separate authoritative records.
